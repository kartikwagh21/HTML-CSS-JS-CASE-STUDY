# HTML-CSS-JS-CASE-STUDY

GearLease: Photography Equipment Rental

GearLease is a simple web-based application that allows users to browse and rent professional photography equipment such as cameras and lenses. The platform includes an equipment catalog and a booking system with an availability check and rental duration selection. The project is built using basic front-end technologies and demonstrates how a rental service website can work with features like equipment previews, booking forms, and a damage deposit calculator.

Features :

- Equipment catalog for cameras and lenses

- Simple booking form for rental requests

- Availability check for selected dates

- Damage deposit calculator using JavaScript

- Image zoom overlay for better equipment preview

Tech Stack : 

- HTML5
- CSS3
- JavaScript
